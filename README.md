# Information Management System

Comprehensive information management system for client tracking, education, counselling, and empowerment programs.

## Features
- Client Profiling & Tracking
- Education Department Integration
- Counselling Department Integration
- Reporting & Export functionality

## Getting Started

1. Clone the repository
2. Install dependencies with `npm install`
3. Run the development server with `npm run dev`

## Build for Production
Run `npm run build` to generate the production bundle.
